LoomClone is my own version of [Loom](https://loom.com/) – a native macOS app for recording, a web app for managing them and public pages which serve them to users. I've been a heavy Loom user for years but always had gripes: I don't own the canonical URLs my videos live on, I've got little control over how they're served, and the camera feed is never quite first-class. So I built the thing I actually wanted.

It's built purely for me and is my first proper native macOS app, so I learned a _ton_ along the way. I've written about it in a [series of articles](/writing/loomclone-part-1/).
