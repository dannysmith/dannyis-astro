```mermaid
    A[Start] --> B{Is it working?}

    B -->|No| D[Debug]
    D --> B
    subgraph G[Grouped]

    end
```

### Sequence Diagram

```mermaid
sequenceDiagram
    participant Alice
    participant Bob
    Alice->>Bob: Hello Bob!
    activate Bob
    loop Healthcheck
        Bob->>Bob: Think
    end
    Note right of Bob: Rational thoughts prevail!
    Bob-->>Alice: Great!
    deactivate Bob
```

### Gantt Chart

```mermaid
gantt
    title A Gantt Diagram
    dateFormat YYYY-MM-DD
    section Section
        A task          :a1, 2024-01-01, 30d
        Another task    :after a1, 20d
    section Another
        Task in Another :2024-01-12, 12d
        another task    :24d
```
